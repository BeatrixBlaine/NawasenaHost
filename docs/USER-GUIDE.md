# Admin panel user guide

Works on desktop, tablet and phone. On small screens the sidebar opens with the menu button.

| Page | Who | What you do |
|---|---|---|
| Dashboard | all | Revenue, bookings, occupancy, today's arrivals and departures, charts. Choose the period at the top. |
| Hotels | ADMIN | Add, edit, remove hotels. ADMIN switches the active hotel from the sidebar. |
| Rooms | ADMIN, MANAGER | Add and edit rooms, price, capacity, type. |
| Inventory | ADMIN, MANAGER, STAFF | See free rooms per day and occupancy, block a room for maintenance, unblock it, initialize inventory. |
| Bookings | all | Filter by status, source or date. Open a booking to confirm, complete (check-out) or cancel it with a reason. A confirmed (paid) booking can be cancelled by MANAGER or ADMIN until its check-out date, the rooms are released and the payment is refunded automatically. A completed stay cannot be cancelled. |
| New booking | all | Choose dates, pick a free room, fill in the guest. |
| Payments | ADMIN, MANAGER | Payments list, revenue report, refunds. |
| Customers | all | Search, open and edit guests, see their bookings. |
| Users | ADMIN, MANAGER | Create accounts (MANAGER can create STAFF only), disable or edit. |
| Audit logs | ADMIN, MANAGER | Who did what, filter by entity or user. |

If you see "changed by someone else", reload the page and repeat the change.
